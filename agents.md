# Blog Project - Agent Context

Personal blog for Sam Rhea, built with Astro as a fully static site and served by Cloudflare Workers static assets.

## Tech Stack

- **Framework**: Astro 7 (static output, no adapter, no server code)
- **Markdown**: Sätteri (Astro's default processor) with small plugins in `src/markdown/`
- **Styling**: Tailwind CSS 4 (CSS-first config in `src/styles/global.css`) with the typography plugin
- **Fonts**: Inter for text and UI, Newsreader for display headings, both self-hosted through Astro's fonts API (`fonts` in `astro.config.mjs`)
- **Hosting**: Cloudflare Worker `blog` with static assets only (`wrangler.jsonc`), deployed by Workers Builds

## Listing Pages

All listing pages are static and generated by `src/pages/[...path].astro`, 15 posts per page:

- Homepage tabs, defined in `FILTERS` in `src/lib/content.ts`:
  - `/` (All): everything except reading posts
  - `/highlights/`: posts tagged `hits`
  - `/reading/`: category or tag `reading`
  - `/portugal/`, `/texas/`: category or tag match
  - `/cloudflare/`: posts from `cloudflare.json`
- `/tag/<topic>/`: one page per category or tag that doesn't have a tab
- Later pages append the number: `/reading/2/`, `/tag/walkthrough/3/`

Categories and tags are lowercased by the schema, so `Portugal` and `portugal` are the same topic. Old `/?filter=…&page=…` links are redirected by a small inline script on `/`.

## Posts Schema (`src/content.config.ts`)

```typescript
{
  title: string,
  date: Date,            // "YYYY-MM-DD"
  description?: string,
  category?: string,
  tags: string[],
  draft: boolean,        // drafts are not built
  book?: Book,           // reading posts only, see below
}
```

The URL comes from the `slug` frontmatter field (`slug: "2026/zoes-tale"` → `/posts/2026/zoes-tale/`). Keep it on every post.

## Adding a New Finished Book Post

Reading posts keep the book's facts in a `book` frontmatter object. The build generates the "Not a Book Report" intro, the **What is it?** table (placed after "Why did I read it?"), and the **How did I read it?** table (placed before the notes). Don't write those sections by hand.

### 1. File Creation

Create `src/content/posts/YYYY-MM-DD-book-title-slug.md`, where `YYYY-MM-DD` is the **date you finished the book**.

### 2. Template

```markdown
---
title: "📚 Book Title by Author Name"
date: "YYYY-MM-DD"           # Finish date
draft: false
slug: "YYYY/book-title-slug"
category: "reading"
tags:
  - "reading"
  - "books"
description: "Short one-line description"

book:
  title: "Book Title"
  author: "Author Name"
  published: "YYYY"
  format: "Kindle"           # Kindle | Paperback | Hardcover | Audiobook
  pages: "XXX"               # or `length` for audiobooks, e.g. "11 hrs and 2 mins"
  asin: "B0XXXXXXXX"         # Kindle books; use `isbn` for physical books
  started: "Month DD, YYYY"
  finished: "Month DD, YYYY"
  places:
    - "Lisbon"
    - "Sintra"
---

## Why did I read it?
[Personal context about why you chose this book]

### Publisher Summary

[Optional: Copy the publisher's book description]

## Notes - No Spoilers
* [Your thoughts and observations]
* [Keep them spoiler-free]
* [Use bullet points]
```

Optional `book` fields: `narrator` (audiobooks), `amazon` (a product URL, rendered as a "Link" row), `isbn` instead of `asin`.

### 3. Emoji Conventions in Titles

Add emojis to the title to indicate progression in a series or special characteristics:
- Single book: `📚 Book Title`
- First in series: `📚 Book Title`
- Second in series: `📚📚 Book Title`
- Third in series: `📚📚📚 Book Title`
- Or use thematic emojis: `🤖 Robot Book`, `🚀 Space Book`, etc.

For the Bobiverse series specifically, use robot + person emojis:
- Book 1: `🤖👨 We Are Legion (We Are Bob)`
- Book 2: `👨👨 For We Are Many`
- Book 3: `👨👨👨 All These Worlds`

### 4. Key Details

- `category: "reading"` is what puts the post under the Reading tab.
- The finish date goes in both `date` (as `YYYY-MM-DD`) and `book.finished` (as `Month DD, YYYY`).
- For Kindle books, use the ASIN from the Amazon product page; for physical books, use the ISBN.
- Page count is fine to approximate for Kindle books.
- `places` is a list of specific locations (cities, flights, etc.); they render comma-separated.

### 5. Content Guidelines

**Why did I read it?** Brief (1-3 sentences): personal context or how you found the book.

**Publisher Summary:** Optional. Copy from Amazon or the publisher and keep the original formatting.

**Notes:** Bullet points only, NO SPOILERS. Personal reactions and observations; writing style, pacing and characters are fine without plot details.

### 6. Verification

1. Filename uses the finish date: `YYYY-MM-DD-slug.md`
2. `category: "reading"` is set
3. `date` and `book.finished` agree
4. Notes are spoiler-free
5. `npm run build` passes (it type-checks, validates frontmatter against the schema, and checks internal links)

### 7. Examples to Reference

- `2025-12-21-we-are-legion.md` - First in series
- `2025-12-24-for-we-are-many.md` - Second in series
- `2025-12-27-all-these-worlds.md` - Third in series

## Images

Post images are hosted on Cloudflare Images (`imagedelivery.net/BO71HffCLgVKrpfgjL7r7Q/<id>/public`). Write them as normal Markdown images with the `public` variant. The build adds `width`/`height` from `src/data/image-sizes.json` and a `srcset` of smaller flexible-variant sizes (`w=640`, `w=1280`). Flexible variants are enabled on the account. Commit `image-sizes.json` when a build adds new entries.

## Styling

- Colors are semantic `@theme` tokens in `src/styles/global.css` (`canvas`, `raised`, `elevated`, `line`, `fg`, `fg-2`, `fg-3`, `accent`, plus topic tints). Use them instead of raw colors; light mode only swaps their values.
- The site follows the system color scheme: dark is gold on ink, light is cobalt on warm white.
- Every post title starts with emoji. `splitTitle()` in `src/lib/content.ts` separates them, and `EmojiTile` shows them as the post's icon, tinted by topic (`tintFor()`). The tile shares a view transition name between the list and the post page, so it morphs between them.
- Shared classes in `global.css`: `.eyebrow` (small labels), `.link`, `.glass` (the nav material), `.tile`, `.scroll-edge` (softens content as it scrolls under the nav).
- Listing pages have no titles: the topic picker is the header, and it sits in the same place on every page.
- Post bodies use Tailwind Typography (`prose`), mapped onto the tokens once on `.prose` in `global.css`. Code blocks use Shiki's `vitesse-light`/`vitesse-dark` themes, picked by color scheme.
- Monospace text uses the system UI monospace font and appears only in code.

## Commands

```bash
npm run dev      # Start dev server

```

## Deployment

The site is the Worker `blog` on Sam's personal Cloudflare account, with static assets only and no Worker code. Workers Builds runs `npm run build` and then `npx wrangler deploy` on every push to `main`. Other branches get preview versions. `.node-version` pins the Node version for the build.
